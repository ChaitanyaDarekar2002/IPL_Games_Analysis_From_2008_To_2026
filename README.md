# 🏏 IPL Games Analysis From 2008 to 2026

## 📊 Project Overview

This project provides a comprehensive analysis of **Indian Premier League (IPL) games from 2008 to 2026** using data analytics and visualization techniques.

The objective is to explore IPL match data, identify important trends, analyze team and player performances, and understand how the tournament has evolved over the years.

## 🎯 Objectives

* Analyze IPL matches from **2008 to 2026**
* Compare team performances across different seasons
* Analyze wins, losses, and match results
* Identify the most successful teams
* Analyze player performances
* Explore toss decisions and their impact on match results
* Analyze venues and cities hosting IPL matches
* Study season-wise trends and patterns
* Create interactive dashboards for better visualization

## 📁 Dataset

The analysis uses IPL match-related data containing information such as:

* Match ID
* Season
* Match date
* Teams
* Venue
* City
* Toss winner
* Toss decision
* Match winner
* Player of the Match
* Match result
* Umpires
* Other match-level information
